# Contributing

Use Node.js 24 and install with `npm ci`. For code changes run the checks in README. Keep React out of the numerical engine. Include units and a reproducible fixture for changes to model behavior. Update MODEL_SPEC.md, the associated experiments and evidence register if changing economic assumptions. Bump the export model version when changing semantics that affect replay.

For educational changes, cite the passage that supports the specific claim. Mark example parameters as synthetic and state limitations wherever readers use them. Keep controls keyboard operable and charts understandable with labels, line patterns and accessible data tables.

Contributions to original code are MIT. Contributions to original educational prose and diagrams are CC BY 4.0. Identify any third-party material and its terms.
